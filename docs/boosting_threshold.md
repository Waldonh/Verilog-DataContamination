# Boosting 模型（CatBoost-5f）训练阈值 τ* 的获取步骤

> 本文档详细说明集成探测器（CatBoost-5f）的决策阈值 τ* 是如何得到的。该阈值用于把模型的污染概率 p 转成"污染/干净"的二值判定，是 benchmark 污染率检测与单方法对比中判定污染样本的依据。

---

## 背景：阈值 τ* 的用途

CatBoost-5f 对每条样本输出一个污染概率 p ∈ [0, 1]（正类的概率）。要把连续概率转成二值判定（污染 = 1 / 干净 = 0），需要一个阈值 τ*：

```
pred = (p >= τ*)    # p 大于等于阈值则判为污染
```

τ* 是在**训练阶段**通过 out-of-fold（OOF）交叉验证确定下来的，而不是在测试/benchmark 阶段临时调的。

---

## 第一步：构造训练集

- **训练源**：CodeV + OriGen（C+O 双源）。
- 每个模型的数据：`all_1000`（500 正 + 500 负），去掉 `test_200`（100 正 + 100 负），得到训练部分 400 正 + 400 负。
- 两个模型合并：**共 1600 条训练样本（800 正 + 800 负）**。
- **特征**：最优 5f（DCPDD、Reference、neighbor、mink_0.2、zlib），不做归一化。

## 第二步：5 折分层交叉验证，得到 OOF 预测

采用 `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`：

1. 把 1600 条训练样本分成 5 折，**分层划分**（每折的正负比例都保持 1:1）；
2. 对每一折：
   - 用其余 4 折训练一个 CatBoost（iterations=900, depth=6, learning_rate=0.03, seed=42）；
   - 在当前这一折上做 `predict_proba`，取正类概率作为预测；
3. 把 5 折的预测拼起来，得到**每个训练样本都有一个 OOF 预测概率 p**（这个 p 是该样本"没有被它所在折的模型训练过"时得到的预测）。

## 第三步：在 OOF 预测上搜索最优阈值 τ*

在概率范围 `[0.05, 0.95]` 内，以步长 `0.005` 遍历候选阈值 t：

```
对每个 t:
    pred = (oof >= t)                          # 用 t 做二值判定
    F1(t) = f1_score(y_train, pred)            # 与真实标签算 F1

τ* = argmax_t  F1(t)                            # 取 F1 最大的那个 t
```

最终得到 **τ* = 0.4050**（此时 OOF F1 ≈ 0.83）。

---

## 为什么用 OOF 而不是直接在训练集上搜阈值

关键在于**避免过拟合**：

- 如果直接在"模型见过的训练样本"上搜阈值，模型在这些样本上预测过于自信，搜出来的阈值会**过于乐观**（比如把阈值调得很高，看似 F1 很高，但换到没见过的新样本就崩了）；
- OOF 预测里，每个样本都是由**没训练过它的那折模型**预测的，因此更接近模型"对未见样本"的真实表现；
- 在 OOF 上搜出的 τ* 才是模型泛化意义上的最优决策边界。

---

## 小结

| 步骤 | 内容 |
|---|---|
| 训练集 | C+O，1600 条（800 正 + 800 负），5f 特征 |
| OOF | 5 折分层 CV，每样本得到"未见过"的预测概率 p |
| 阈值搜索 | [0.05, 0.95] 步长 0.005，最大化 OOF F1 |
| 结果 | **τ* = 0.4050** |

这个 τ* 在训练阶段一次定好，之后在 9 模型 × 6 benchmark 的污染率检测中直接使用（`p ≥ τ*` 判污染），不再针对每个 benchmark 单独调整。
